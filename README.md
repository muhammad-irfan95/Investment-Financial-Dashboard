# Investment & Financial Analysis Dashboard

## 📌 Project Overview
This project is an interactive **Investment & Financial Analysis Dashboard** created using **Microsoft Power BI**, supported by **MySQL** and **Python** for data preparation and cleaning[span_2](start_span)[span_2](end_span).

The dashboard provides comprehensive insights into capital investments, profit generation, monthly payouts, investor distribution, fund-type performance, payment modes, and top-performing participants and partners[span_3](start_span)[span_3](end_span).

The main objective is to transform raw investment and payout records into clear, actionable financial insights for better decision-making[span_4](start_span)[span_4](end_span).

## 📌 Dashboard Features

1. **Total Capital by Year and Month (Trend)**
   * Tracks monthly growth and comparison between Invested Capital and Profit Generated over time[span_5](start_span)[span_5](end_span).
2. **Total Capital by Fund Type**
   * Analyzes capital allocation across different fund plans (such as *Assured Commission Pro*, *Assured Commission Lite*, *Custom Fund*, etc.)[span_6](start_span)[span_6](end_span).
3. **Total Capital by Payment Mode**
   * Visualizes investment distribution across payment channels (*NEFT/IMPS*, *Cheque*, *Cash*, and *Other*)[span_7](start_span)[span_7](end_span).
4. **Top 5 Participants by Capital**
   * Highlights top investors along with their Participant ID, Bank details, and Invested Capital[span_8](start_span)[span_8](end_span).
5. **Top 5 Partners by Total Commission**
   * Displays top-performing partners, Partner IDs, Bank details, and earned Commission[span_9](start_span)[span_9](end_span).
6. **Interactive Slicers & Filters**
   * Allows dynamic filtering across the entire report by:
     * **Investment Date**
     * **Fund Type**
     * **Deposit Branch**
     * **Status**

## 🚀 How to Use
1. Download or clone this repository to your local machine.
2. Open the `.pbix` file in **Microsoft Power BI Desktop**.
3. Use the top slicers (**Investment Date, Fund Type, Deposit Branch, Status**) to filter and explore specific segments[span_19](start_span)[span_19](end_span).
4. Hover over charts and tables for detailed tooltips and dynamic cross-filtering[span_20](start_span)[span_20](end_span).
